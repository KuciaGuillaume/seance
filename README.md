# Séance

Séance est une app Android TV pour regarder les films, séries et chaînes de son abonnement IPTV,
pensée pour la télécommande.

Ce dépôt ne contient que la page de téléchargement et les versions publiées (onglet
**Releases**). Il n'y a ni code source ni donnée personnelle ici.

## Installer Séance sur une télé Android TV

Aucun ordinateur n'est nécessaire.

1. Sur la télé, ouvre le **Google Play Store** et installe l'app gratuite **Downloader**
   (éditeur AFTVnews).
2. Ouvre Downloader et tape l'adresse **`kuciaguillaume.github.io/seance`**, puis **Go**.
3. Sur la page qui s'ouvre, choisis **Télécharger Séance**, puis **Installer**.
4. Si la télé indique que l'installation est bloquée : autorise **Downloader** à installer des
   applications (la télé propose d'ouvrir le bon réglage ; sinon *Paramètres → Applications →
   Sécurité et restrictions → Sources inconnues*), puis reviens et réessaie.
5. Ouvre Séance et suis les étapes à l'écran.

Lien direct vers la dernière version :
<https://github.com/KuciaGuillaume/seance/releases/latest/download/seance.apk>

## Mises à jour

Elles sont automatiques. À chaque lancement, Séance regarde s'il existe une nouvelle version, la
télécharge et ouvre l'installation : Android demande toujours une confirmation, il suffit
d'appuyer sur **Installer**. Tes profils, ta liste et ton abonnement sont conservés.

La première fois, Android peut demander d'autoriser **Séance** à installer des applications :
accepte, c'est ce qui lui permet de se mettre à jour. Si quelque chose bloque une mise à jour,
Séance l'affiche clairement et explique quoi faire.
